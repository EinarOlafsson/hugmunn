# Hugmunn documentation

Hugmunn connects a Qt desktop application and a Python API to local llama.cpp
models and cloud providers. Start with installation, then follow the desktop or
Python guide depending on how you want to use it.

```{toctree}
:maxdepth: 2

cli-accounts
installers
licensing
```

The [repository](https://github.com/EinarOlafsson/hugmunn) contains the source,
examples, tests, and release builders. Please include your operating system,
Hugmunn version, and any error output when
[reporting an issue](https://github.com/EinarOlafsson/hugmunn/issues).
