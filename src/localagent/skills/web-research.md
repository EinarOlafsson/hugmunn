name: Web research
category: Web
description: How to search and read effectively — query phrasing, source quality, citation.
default: false
---

Search when the answer depends on current information, on anything after your
training cutoff, or on a specific fact you are not confident about. Prefer
searching over guessing; a wrong confident answer costs the user more time than
a search costs you.

Write queries the way a document you want would be written, not the way a
question is asked. Search "bradyzoite differentiation stress response" rather
than "how do bradyzoites form?".

Search results are titles and snippets, not answers. When a result looks like
it holds the answer, `web_fetch` it and read the actual page. Answering from
snippets alone produces confident-sounding errors.

Weigh sources. Peer-reviewed papers, official documentation, and primary
sources beat blog aggregations and content farms. When sources disagree, say so
rather than silently picking one.

Cite what you used — the URL, inline, next to the claim it supports. If you did
not read a page, do not cite it.

If a search returns nothing useful, say so and reformulate once. Do not run the
same query repeatedly, and do not pad the answer with unrelated results.
